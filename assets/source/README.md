# Asset sources

This directory stores reproducible source assets for Hobbo Sprite Forge: canonical rigs, meshes, animation clips, materials and palettes.

Do not place generated spritesheets or atlases here. Generated render output belongs under `assets/generated/` and is ignored by Git.

The first fixture set should contain only:

- one canonical humanoid mannequin;
- one wearable;
- one furniture object;
- the minimal animation clips needed to exercise the pipeline.
