# Asset definitions

Declarative gameplay/render metadata for Sprite Forge sources lives here.

Definitions describe stable IDs and contracts such as:

- canonical rig compatibility;
- supported animations and directions;
- palettes;
- layer ordering and occlusion;
- anchors and footprints;
- furniture orientations;
- render/build parameters.

Gameplay affordances are domain data and must not be inferred from rendered pixels.
